# Chinese Report Guidelines

Render a Simplified Chinese overview report from `index.json` and `analysis_zh.json`.

Required sections:

- `主题概览`
- `研究脉络`
- `逐篇论文分析`
- `论文间关系`
- `方法范式比较`
- `未来趋势`
- `限制与待补充信息`

Rules:

- Preserve original English paper titles exactly.
- Keep BibTeX entries in English.
- Label metadata-only papers explicitly as `仅元数据，未发现合法开放 PDF`.
- Include ranked paper list and synthesis sections.
- State when analysis is based only on title/abstract/metadata because PDF extraction failed or no legal PDF was available.
- Do not fabricate findings unavailable from metadata, abstracts, extracted PDF text, or Codex analysis.
