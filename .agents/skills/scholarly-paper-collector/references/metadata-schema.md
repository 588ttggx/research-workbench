# Metadata Schema

`attachments/papers/index.json` contains:

- `schema_version`: schema version string.
- `query`: original topic query.
- `generated_at`: ISO-8601 UTC timestamp.
- `sources_requested`: source names requested.
- `warnings`: non-fatal provider or download warnings.
- `papers`: list of normalized paper objects.

Each paper object uses stable keys:

- `paper_id`: local stable id such as `p001`.
- `title`: original English title.
- `authors`: list of names.
- `year`: integer or null.
- `venue`: venue/source string.
- `abstract`: English abstract when available.
- `doi`, `arxiv_id`, `semantic_scholar_id`, `openalex_id`: identifiers when available.
- `source_records`: provider records that contributed metadata.
- `citation_count`, `influential_citation_count`: impact signals when available.
- `access`: legal access object.
- `ranking`: score components.
- `metadata_rank`, `analysis_rank`, `final_rank`: rank fields.
- `extraction`: optional PDF text extraction status recorded by `prepare_analysis_packets.py`.

`access.status` values:

- `downloaded_oa_pdf`
- `oa_pdf_available_not_downloaded`
- `oa_landing_only`
- `metadata_only_no_legal_pdf`
- `download_failed_retryable`
- `download_blocked_by_policy`

`analysis_zh.json` is generated by Codex from `analysis_packets.json`, not by the collection scripts. It must preserve `title` exactly.

For each paper with a legal PDF, `access.oa_source` must be one of the allowed source families and `access.local_pdf_path` must point under `attachments/papers/`.
